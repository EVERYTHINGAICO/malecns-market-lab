# Roadmap and acceptance gates

- [x] State falsifiable hypotheses and controls.
- [x] Publish incomplete prerequisites rather than fabricated results.
- [x] Add tested temporal/metric primitives and CI configuration.
- [ ] Freeze baseline implementation and effective risk configuration privately; publish hashes and adapter contract.
- [ ] Audit full point-in-time market universe, availability, costs and dividend feasibility.
- [ ] Reproduce baseline decisions and execution using a common validated simulator.
- [ ] Freeze actual date boundaries, practical effect size, embargo, seeds and compute budget.
- [ ] Implement B; benchmark C/D without inspecting final test.
- [ ] Run chronological development walk-forward and record all trials.
- [ ] Run the sealed OOS evaluation and statistical controls once.
- [ ] Conduct a bounded prospective shadow evaluation if justified.
- [ ] Investigate E/F on a new holdout under matched training budgets.
- [ ] Publish decision and limitations, including negative results.

Stop if the baseline cannot be reproduced, data provenance is missing, costs are unidentified, or statistical power is inadequate. Resolve the prerequisite or record NEED MORE DATA. Do not lower scientific standards to complete a checklist.
